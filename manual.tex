\section{SYSTEM DESCRIPTION}
This application is used for encrypting and decrypting text data in the Czech language. The system utilizes 12 different algorithms and fully supports Czech diacritics (ěščřžýáíéóňďť).

\section{AVAILABLE MODULES}
\begin{itemize}
    \item \texttt{Encryptor} - Module for transforming plain text into encrypted form.
    \item \texttt{Decryptor} - Module for decoding received messages.
\end{itemize}

\section{IMPLEMENTED ALGORITHMS}
\begin{itemize}
    \item \textbf{Letters backwards} - Reversal of character order.
    \item \textbf{Caesar cipher} - Shift in the Czech alphabet (41 characters).
    \item \textbf{Gronsfeld} - Advanced polyalphabetic cipher with a numeric key.
    \item \textbf{Binary and HEX code} - Conversion at the UTF-8 byte level.
    \item \textbf{Base64} - Standard encoding for data transmission.
    \item \textbf{Leet Speak} - Hacker substitution of characters with numbers.
    \item \textbf{Morse code} - Classic radio communication (simplified).
\end{itemize}

\section{INSTALLATION AND EXECUTION}
To download and run the application, Git and a Python 3 interpreter must be installed.
\begin{Verbatim}[frame=single, rulecolor=\color{text_zelena}, fontsize=\large]
$ git clone https://github.com/susjantux/czech_cipher_app.git
$ cd czech_cipher_app
$ python czech_cipher_app.py
\end{Verbatim}
